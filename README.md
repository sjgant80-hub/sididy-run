## What it is

sididy-run is a deterministic, zero-dependency estate tool. The runtime layer — run-local: bring the whole estate up as one persistent, governed live mesh on your own electric. The wisps dance within a power budget, then rest clean. It never throws on hostile input and
produces the same result on every machine.

## API

- `RunLocal`
- `default`

## Verify

```bash
npm test
```

konomify before this build joins the mesh.
